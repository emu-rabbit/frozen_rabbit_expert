# v0.25 迭代結案摘要

## 結論

`generic-craft-objective-capability-portfolio-v0.25.0` 沒有送交完整 overnight。日間 broad evidence 相對 v0.22 只有 Stable 持平、Balanced `+3/-0`、Aggressive `+4/-0`，9,000 paired cases 的 practical effect 僅約 0.075／0.1 個百分點；其主要成果是 objective／risk 契約清理、shared continuation、action budget 與報告長度量尺，不足以單獨支付一次長跑成本。

## 後續決定

使用者要求繼續只在 Rust 累積多方面提升。v0.25 因此成為 v0.26–v0.30 的策略基底：progress-only 品質護欄、專家資源、過早完工 bank、wrapper 攤平與專家資源 guard。新的 active handoff 由 `.agents/overnight_review_brief.md` 擁有。

- v0.23 行為等同 v0.22，v0.24 只有窄 continuation，v0.25 多數是契約與 evidence 改善；版本數不能冒充 solver uplift。
