# 歷史文件庫

此目錄保存已被目前方向取代、但仍具有研究或回歸價值的文件。

## 使用規則

- 一般任務不讀取本目錄。
- 只有 active owner 明確連入某份歷史證據，或任務要求重播舊結果時才讀取。
- 歷史文件中的「目前」、「下一步」、「必須」與版本敘述，都以該文件當時的時間點解讀。
- 歷史內容不能覆寫 [`AGENTS.md`](../../AGENTS.md)、[`current_state.md`](../current_state.md) 或 active canonical owner。
- 原文原則上保持不變；更正目前方向時修改 active owner，不回頭重寫歷史。

## 內容

- [`handoffs/`](handoffs/)：舊研究、訓練與產品化交接。
- [`roadmaps/`](roadmaps/)：已完成或被取代的舊 roadmap。
- [`research/`](research/)：不再代表目前產品母體的舊量尺。
