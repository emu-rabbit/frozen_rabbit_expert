## Cosmic mission selection data

`apps/web/public/mission-data` is generated by
`tools/generate-cosmic-mission-data`. The small content-addressed bundle uses
selected Cosmic Exploration mission identities from the pinned catalog and
projects localized item names plus crafting-related food and medicine bonuses
from a fixed Teamcraft revision. Mission names are joined by mission recipe ID
against pinned English/Japanese, Traditional Chinese, and Simplified Chinese
game-data revisions, with English fallback when a locale has no matching row.
It includes only consumables affecting
Craftsmanship, Control, or CP, while retaining NQ/HQ percentages and caps.

- Teamcraft repository: <https://github.com/ffxiv-teamcraft/ffxiv-teamcraft>
- Teamcraft revision: `28cd7763e23781cd17650a7ae7a336688815360a`
- License: MIT; the generated bundle includes a content-addressed copy of the notice
- Mission table revision: `c142b1269a76e9e3fffc42f984a5f193ba565ddc`
- Japanese mission names: `xivapi/ffxiv-datamining` at the same mission revision
- Traditional Chinese mission names: `thewakingsands/ffxiv-datamining-tc` at `e203c7e46dd80fd2a967e5741b30e3c9fad0c767`
- Simplified Chinese mission names: `thewakingsands/ffxiv-datamining-cn` at `991071b8fb6c56c00417ad60d72a4b1556e2ccff`
- XIVAPI class/job icon URLs: `https://xivapi.com/cj/1/{job}.png`
- XIVAPI item icon URLs: `https://v2.xivapi.com/api/asset`

The Web application links to XIVAPI icon URLs directly. It does not repackage
or host the class/job or item PNG files.

## Cosmic Exploration expert recipe catalog

`packages/data/src/generated/cosmicExpertRecipes.generated.ts` contains
recipe, item, job, condition and mission identity fields generated from a
pinned XIVAPI v2 snapshot and pinned CSV revisions from
`xivapi/ffxiv-datamining`. These generated values are FINAL FANTASY XIV game
materials; the importer records exact upstream revisions and a canonical
content hash so changes fail closed instead of silently drifting.
